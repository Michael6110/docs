Once you have filled in all sections of the Ghana Gas Site Brief, you can export a professional PDF using your browser's print function. The brief includes print-specific CSS that hides the editing controls and action bar, and optimises the layout for printed pages.

## Exporting to PDF

<Steps>
  <Step title="Save your work">
    Complete all edits and click **Save Progress** to ensure your latest changes are stored before exporting.
  </Step>
  <Step title="Review all sections">
    Scroll through the entire brief and replace any remaining `[placeholder]` text with accurate, period-specific information.
  </Step>
  <Step title="Open the print dialog">
    Click **Print / Export PDF** in the sticky action bar at the bottom of the page. Your browser's print dialog will open.
  </Step>
  <Step title="Set the destination">
    In the **Destination** field, select **Save as PDF**.
  </Step>
  <Step title="Set the paper size">
    Set **Paper size** to **A4** or **Letter** depending on your organisation's document standard.
  </Step>
  <Step title="Adjust margins">
    Set **Margins** to **None** or **Minimum** to make the best use of the page area and avoid unnecessary white space around the layout.
  </Step>
  <Step title="Enable background graphics">
    Ensure **Background graphics** is enabled. This is required for colour-coded status bars, progress bar fills, and department badge colours to appear correctly in the PDF.
  </Step>
  <Step title="Save the PDF">
    Click **Save** and choose a destination folder. Name the file with the issue number and reporting period for easy identification (e.g., `GhanaGas-SiteBrief-Issue001-Apr2026.pdf`).
  </Step>
</Steps>

## Recommended browser settings

<Tabs>
  <Tab title="Chrome / Edge">
    Open the print dialog via **Print / Export PDF** or **Ctrl + P**.

    | Setting | Recommended value |
    |---|---|
    | Destination | Save as PDF |
    | Paper size | A4 or Letter |
    | Orientation | Portrait |
    | Margins | None or Minimum |
    | Scale | Default (100%) |
    | Background graphics | Checked (enabled) |

    To access **Scale** and **Background graphics**, click **More settings** to expand the full options panel.
  </Tab>
  <Tab title="Firefox">
    Open the print dialog via **Print / Export PDF** or **Ctrl + P**.

    | Setting | Recommended value |
    |---|---|
    | Destination / Printer | Print to PDF |
    | Paper size | A4 or Letter |
    | Orientation | Portrait |
    | Scale | 100% |
    | Print backgrounds | Checked (enabled) |

    The **Print backgrounds** option is found in the main print panel. Ensure it is checked so that all coloured elements render correctly.
  </Tab>
</Tabs>

## What the PDF includes and excludes

**Included in the PDF:**

- All 7 sections: Project Progress Dashboard, Gas Flow Rate Register, Community Updates, Roads, Pipeline, Facilities, and Technical Services
- All project cards with their colour-coded progress bars and completion percentages
- The full gas flow rate table with stream names, values, units, status indicators, remarks, and recorded dates
- All department cards with their names, status badges, update body text, and metadata rows

**Excluded from the PDF (hidden via print CSS):**

- The sticky action bar containing the Save Progress and Print / Export PDF buttons
- The **✎ EDITING ON** hint label
- The golden hover highlight and focus outline on editable fields

## Physical printing

The **Print / Export PDF** button also works for printing directly to a physical printer. When the print dialog opens, select your printer as the destination instead of **Save as PDF**, then click **Print**. All the same margin and background graphics settings apply for the best printed output.

<Tip>
For a cleaner PDF layout, collapse your browser's developer tools panel and set the page zoom to 100% before opening the print dialog. Chrome's print preview shows exactly what will appear in the exported PDF, so use it to check the layout before saving.
</Tip>

<Note>
The brief does not include a page-break configuration. For long reports, some sections may split across pages. If this happens, adjust the print scale — try 80–90% — in the print dialog's **Scale** or **More settings** panel to fit more content on each page.
</Note>
